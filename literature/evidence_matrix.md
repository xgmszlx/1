# Active SLAM evidence and implementation matrix

Updated: 2026-08-13. This is a decision document, not a bibliography dump.

## Evidence rules

- `FULLTEXT_VERIFIED`: the paper full text was inspected locally or on an author/publisher page.
- `ABSTRACT_VERIFIED`: only metadata and abstract-level claims are used.
- `CODE_VERIFIED`: the official repository structure, documentation, and license metadata were inspected.
- A fixed-trajectory dataset can validate a SLAM-health estimator or mapping backend, but **cannot validate counterfactual exploration decisions**. Closed-loop planning claims require an interactive simulator or a robot experiment.
- GitHub stars are recorded only as a rough maintenance/adoption signal as of 2026-08-13, never as scientific evidence.

## Excluded or down-ranked routes

1. **Pure NBV/semantic weighting around the old repository**: the old code is an AI scaffold and its source paper is not a high-confidence implementation anchor.
2. **A generic adaptive weighted sum of coverage, uncertainty, and distance**: FIT-SLAM, UncertaintyMap, B-ActiveSEAL, graph-SLAM work, and recent information-objective papers make the novelty weak.
3. **End-to-end DRL or imitation learning**: training/supervision cost, evaluation variance, and sim-to-real risk are disproportionate for the current coding level and publication target.
4. **3-D UAV/NeRF/Gaussian-splatting exploration**: mismatched actuation and sensors, high compute, and a much larger systems burden.
5. **A static-dataset-only “active SLAM” paper**: no counterfactual action is executed, so it cannot substantiate the active-planning claim.

## Current evidence-backed gap

The literature separately covers visual localizability-aware planning, LiDAR localizability-aware planning, loop-aware recovery, and multi-sensor SLAM fusion. After targeted searches combining `active SLAM`, `active exploration`, `sensor health`, `cross-modal`, `RGB-D/camera`, and `2D LiDAR`, what has **not been found in the inspected corpus** is a lightweight ROS2 ground-robot policy that:

1. estimates **modality-specific online localization health** for an RGB-D camera and a 2-D LiDAR;
2. distinguishes common-mode risk from complementary failure (for example, low visual texture while laser geometry remains informative, versus a long geometrically repetitive corridor);
3. changes frontier/path/revisit behavior only when calibrated risk warrants it; and
4. is evaluated both on sensor-matched public real data and in a public closed-loop benchmark with localization/map-quality metrics.

This is a candidate gap, not proof of novelty or an exhaustive-search claim. The closest boundaries are visual-only perception-aware exploration (Yu 2025; Shi 2026), LiDAR-only localizability planning (LF-3PM), health-aware complementary estimator fusion (LOCUS; CompSLAM), and ambiguity/loop-aware active recovery (ARAS; Zhao 2024). The minimum experiment supports continuing only if recovery overhead is explicitly constrained.
